# LandingHealth homepage

A minimal, responsive LandingHealth site built with Next.js App Router, TypeScript, Tailwind CSS, and pnpm. The top navigation links to Product, Solution, Schedule, and About pages.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

To verify or serve the production build:

```bash
pnpm build
pnpm start
```
